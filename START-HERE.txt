RESEARCH REPORT READER 4.6 — SESSION-ONLY WEBSITE

1. Extract this download.
2. Open https://dash.cloudflare.com/ and sign in or create a Cloudflare account.
3. Go to Workers & Pages > Create application > Get started > Drag and drop your files.
   Choose Pages / a static site if the dashboard offers multiple choices.
4. Pick a project name and upload WEBSITE-UPLOAD.zip from this package.
   Upload that inner ZIP as it is. It already contains the finished website.
5. Select Deploy site (or Save and Deploy).
6. Open the supplied .pages.dev link, test a PDF, and send that link to the reader.

Use Cloudflare Pages' free plan. No Render service, paid database, build command,
GitHub repository, or npm installation is needed. A custom domain is optional.
Only the person publishing needs a Cloudflare account; visitors need no account.

HOW TO USE
Open the website on a phone or computer. Choose Morningstar or Argus and select
downloaded PDF reports. For Argus, one file is enough. Use Add another source
later to add the same company's A6 or Options report. Tap a number or Source PDF
to verify it against the original page. All historical and forecast years remain
available. On a phone, choose a fiscal year to read down one column; Show all
years restores the full view. Exports always include all printed periods.

SESSION BEHAVIOR
Reports stay in memory in the current tab. You can switch between them while the
tab remains open. Refreshing, closing, or leaving the page clears the session.
Clear session removes everything immediately after confirmation. Original files
on the device are unchanged. Keep the downloaded PDFs to open them again later.
Mobile browsers may discard a background tab, which also ends the session.
There are no accounts, cloud uploads, report storage, or cross-device syncing.

UPDATES
Use Create a new deployment in the same Cloudflare Pages project, select
Production, and upload the new WEBSITE-UPLOAD.zip. The public link stays the same.

The source folder is for future development; do not upload it to the host.
This package is ready to upload, but has not itself been deployed.

TO MAINTAIN THE CODE (OPTIONAL)
See GITHUB-SETUP.md. The source folder includes a ready-to-publish Git repository.
Readers do not need GitHub, Cloudflare, ChatGPT, or an app installation.
